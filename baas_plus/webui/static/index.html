⏰ 定时执行指引（Windows 任务计划程序）

      

        点击展开：创建每日定时任务的完整步骤
        
    
          
  1. 按 Win+R 输入 taskschd.msc 回车，打开「任务计划程序」
    2. 
          
  2. 右侧点「创建基本任务…」→ 名称随意（如 BAAS-Plus 每日）
    3. 
          
  3. 触发器：选「每天」→ 设置执行时间（建议游戏体力重置后，如 04:05）
    4. 
          
  4. 操作：选「启动程序」
    5. 
          
  5. 「程序或脚本」填 Python 完整路径，例如：
    D:\BAAS\.venv\Scripts\python.exe
    6. 
          
  6. 「添加参数」填：
    -m baas_plus.cli run
    7. 
          
  7. 「起始于」填 BAAS 根目录（必须，BAAS 依赖相对路径读 config/）：
    D:\BAAS
    8. 
          
  8. 点「完成」后，在任务列表双击该任务 → 「条件」页：取消勾选「只有在计算机使用交流电源时才启动任务」（笔记本必改），「设置」页可勾选「如果任务运行时间超过以下时间，停止任务」设 3 小时防卡死
    9. 
        

        
说明：run 默认执行全部启用账号（每个账号独立模拟器实例，串行执行）。
只跑单个账号：-m baas_plus.cli run --account <账号名>。多次执行：在顶部主操作条设置「轮数」（全部账号执行完一轮后立即开始下一轮，无间隔），或命令行加 --times N 覆盖。
若配置不在默认位置，加 --config D:\BAAS-Plus\data\config.json。
